DataStore Migration Guide

Move ALL your players' saved data from your old game to your new game — explained for complete beginners, in the right order.

Quick links (everything you'll need, in one place)

Tip: this page is one long checklist. Just go down step by step — 1, 2, 3... — and don't skip. Each step tells you exactly where to click.

First, 5 words you must know

WordSimple meaning
Experience / UniverseYour whole game. It has a Universe ID (a number).
PlaceOne level inside your game. It has a Place ID.
DataStoreA cloud folder where the game saves things (coins, items...).
KeyOne entry in that folder — usually one player's data.
Open Cloud API keyA secret password that lets a script read/write your DataStores.
The big idea: DataStores do not travel between two games. Your new game starts empty. This toolkit copies everything from old to new so your players keep their progress.
1

Before you startWhat you need

Gather these four things. Everything here is free.

  1. Your old game (the one full of player data) and your new game (the empty one).
  2. A computer with Windows (the commands in this guide are for Windows).
  3. Python 3 installed — don't worry, step 5 shows you how. Get it here.
  4. An Open Cloud API key — step 4 shows you how. Open the key page.
Allow about 20 minutes. Most of the time is waiting for the backup step to download your data.
2

Find your games' IDsUniverse ID & Place ID

You need four numbers total: old universe, old place, new universe, new place.

Open this page:

create.roblox.com → Creations
  1. Find your old game in the list and click it.
  2. Click the … (three dots) menu → choose Copy Universe ID.
  3. Paste it into Notepad and label it OLD UNIVERSE.
  4. For the Place ID: open your game's public page. The URL looks like roblox.com/games/123456789/My-Game. The 123456789 is the Place ID. Save it as OLD PLACE.
  5. Now do exactly the same for your new game → save NEW UNIVERSE and NEW PLACE.
You'll paste these four numbers into config.py in step 7. Keep the Notepad file open.
3

Look at your gameFind your DataStore names

A DataStore name is the word your game uses to open a save folder. You find them in your own game code.

Open your old game in Roblox Studio, then:

  1. Press Ctrl + Shift + F (search across all scripts).
  2. Search for: GetDataStore
  3. Every result looks like this — the text in quotes is a name you need:
local store = DataStoreService:GetDataStore("TimeStats")

Write each name into your Notepad list. Real examples look like:

"ProfileStore V1", "TimeStats", "Donation", "PlayerData_v1_79229339887184"
Some names end with your old place ID (like the last example). That's normal — the toolkit automatically swaps that ending to your new place ID. Just copy the name exactly as it is.
No Studio yet? Install it first: Roblox Studio setup guide.
4

The secret passwordCreate your Open Cloud API key

This key lets the toolkit read your old game and write to your new game. It must have access to both.

Open the Credentials page
  1. Click Create API Key.
  2. Give it any name, e.g. migration.
  3. Under Access Permissions, add both experiences: your old game AND your new game.
  4. Under Permissions, enable the DataStore read and write options.
  5. Click Save & Generate Key, then copy the key (long string of letters and numbers).
  6. Open Notepad, paste the key on a single line, and save it as: 
    C:\Users\You\Downloads\roblox key data.txt
    (change You to your Windows username — use the exact real path, you'll need it in step 7).
NEVER share this key. Not in Discord, not in a GitHub file, not in a screenshot. It's the password to your game's data. The toolkit reads it from this text file — that's the safe way.
5

One-time setupInstall Python

python.org/downloads
  1. Download the latest Python 3 for Windows.
  2. Run the installer. On the first screen, tick the box "Add Python to PATH" — this is important! Then click Install Now.
  3. When it's done, test it. Press Windows key, type cmd, press Enter (this opens the terminal), then type:
python --version
If it prints something like Python 3.12.4, you're ready. If it says "not recognized", re-run the installer and make sure "Add to PATH" is ticked.
6

Get the filesDownload the toolkit

Direct ZIP download Or open the repo
  1. Click Direct ZIP download above (or on the repo: green Code button → Download ZIP).
  2. Right-click the downloaded ZIP → Extract All…
  3. Choose a simple place like C:\Users\You\roblox-datastore-migration.
  4. Now open your terminal (Windows key → type cmd → Enter) and go into that folder:
cd C:\Users\You\roblox-datastore-migration
Tip: type cd (with a space), then drag the folder onto the terminal window — it fills the path for you.
7

Your settingsFill in config.py

First, make your own copy of the example config. In the terminal, inside the repo folder, run:

copy scripts\config.example.py scripts\config.py

Now open scripts\config.py in Notepad and change these lines to your values from steps 2, 3 and 4:

# where your key file is (step 4)
API_KEY_FILE = r"C:\Users\You\Downloads\roblox key data.txt"

# your game numbers (step 2)
OLD_UNIVERSE = 1111111111
NEW_UNIVERSE = 2222222222
OLD_PLACE    = 111111111111
NEW_PLACE    = 222222222222

# the DataStore names you found (step 3)
STORES = [
    "ProfileStore V1",
    "TimeStats",
    "Donation",
]
  1. Replace each number with your real ones.
  2. Replace the STORES list with your own DataStore names (keep the quotes and commas).
  3. Save the file.
Compare with the original config.example.py if you get stuck. And remember: never upload config.py anywhere — it has your paths.
8

Run 1 of 4Back up the old game

This reads every key from your old game and saves it on your PC. It is read-only — your old game is never touched or changed.

python scripts\old_backup.py

You'll see it working through your DataStores. When it's done, a folder called old_backup\ appears with one file per DataStore — that's all your players' data, safe on your computer.

Keep those backup files. They're your parachute — even if everything else failed, your data is safe.
Step 8 details (docs/04)
9

Run 2 of 4Retry anything that failed

Sometimes a download fails (internet hiccup, Roblox rate limit). This command finds and re-tries only the failed ones:

python scripts\retry_errors.py

Run it until it reports nothing left to retry, then continue.

Problems? (docs/09)
10

Run 3 of 4Build the migration plan

This reads your backup, rewrites the old place-id endings to your new place id, and works out a safe merge with anything already in the new game:

python scripts\build_ops.py
  • Numbers (coins, minutes) → keep the maximum of old and new
  • Tables → merged field by field
  • Lists → combined, no duplicates
  • Nothing is ever deleted from the new game

Result: mig\ops.json (the plan). If anything was ambiguous, it's listed in mig\conflicts.txt for you to read.

Step 10 details (docs/05)
11

Run 4 of 4Migrate!

The big one — this writes everything into your new game, 10 threads at a time:

python scripts\migrate_oc.py

Every successful write is noted in mig\applied_keys.jsonl. If it crashes or your PC restarts, just run the same command again — it continues from where it stopped.

Running it twice is safe. Keys that already transferred are skipped automatically.
Step 11 details (docs/06)
12

Final checkVerify in your new game

  1. Open your new game in Roblox Studio and play it.
  2. Check a few players — their coins, items and time should all be there.
  3. Leaderboards need one extra step (see below).
  4. Game passes / VIP: Roblox stores those on their side, not in DataStores — read the guide below.

Why this is safeThe golden rules

Old game read-onlywe only read from your old game — nothing is changed or deleted there.
Backup firsteverything is saved to your PC before a single write happens.
Merge, never wipeexisting new-game data is kept; numbers never go backwards.
Logged & resumableif it stops, run the same command again — it continues, not restarts.
Key stays secretread from a file, never in the code, blocked by .gitignore.
Rate-limit friendlyevery request retries with back-off on 429 / 5xx.
